A

速览

按主题分组的常用 API。签名与默认值对照本机 torch 2.14.0 核对，= 后面是默认值，没写默认值的表示必填。阶段练习见 index.md。

约定：

  • 子模块 一列用简写：nn = torch.nn，nn.functional = torch.nn.functional，optim = torch.optim，lr_scheduler = torch.optim.lr_scheduler，Tensor 表示张量方法（x.sum()）。
  • 创建类函数大多还接受 dtype=None, device=None, requires_grad=False, out=None，下表只在有区别时重复。

API 速查

子模块一览

子模块 里面有什么
torch 张量创建、运算、归约、线性代数、随机数、保存加载
torch.Tensor 张量方法，形状变换、逐元素运算、backward 等
torch.nn 层、损失、容器（Module / Sequential / Linear / LSTM …）
torch.nn.functional 无状态的函数式版本（F.relu / F.cross_entropy）
torch.nn.init 参数初始化（xavier_uniform_ / kaiming_normal_）
torch.nn.utils 梯度裁剪等工具
torch.optim 优化器（SGD / AdamW）
torch.optim.lr_scheduler 学习率调度
torch.utils.data Dataset / DataLoader / TensorDataset / random_split
torch.autograd grad / backward 的底层入口
torch.amp 混合精度 autocast / GradScaler

张量创建

名称 子模块 常用关键字参数 说明
tensor torch dtype、device、requires_grad=False、pin_memory=False 从数据拷贝出一个张量，永远复制
as_tensor torch dtype、device 同数据尽量不复制，共享内存时改动会互相影响
from_numpy torch — 与 ndarray 共享内存，最省事的互转
zeros / ones / empty torch dtype、device、requires_grad、layout *size 传形状；empty 是未初始化，别指望是 0
zeros_like / ones_like / rand_like torch dtype、device、memory_format=preserve_format 复制形状和 dtype，默认沿用输入的 device
full torch dtype、device、requires_grad full(size, fill_value)，用常数填满
arange torch dtype、device、step=1 左闭右开，arange(5) 不需要写 start
linspace torch dtype、device、steps 左闭右闭的等距点，注意 steps 是必填
eye torch m=None、dtype、device 单位矩阵，m 控制列数以得到矩形
rand / randn torch generator=None、dtype、device [0,1) 均匀分布 / 标准正态
randint torch low=0、high、size、dtype、generator 整数随机，dtype 默认 int64
randperm torch dtype=int64、generator 0..n-1 的随机排列，手写 shuffle 常用
normal torch generator=None、out=None normal(mean, std)，两个参数都可以是张量
manual_seed torch — 固定 CPU 随机种子，返回 Generator

形状 / 视图 / 结构变换

名称 子模块 常用关键字参数 说明
reshape Tensor / torch *shape、shape 能复制就复制，最安全的重排
view Tensor *shape 只能在不连续时直接报错，必须接 contiguous()
flatten Tensor / torch start_dim=0、end_dim=-1 展平一段维度；nn.Flatten 默认从 1 开始，两者不同
squeeze / unsqueeze Tensor / torch dim=None 去掉 / 插入长度为 1 的维度，squeeze(dim) 更可控
permute Tensor / torch *dims 任意调换维度顺序，返回视图
transpose Tensor / torch dim0、dim1 只换两个维度，之后往往要 contiguous()
expand / broadcast_to Tensor / torch *size、shape 广播出视图，不复制数据，只扩长度为 1 的维
contiguous Tensor memory_format=contiguous_format 把张量整理成连续内存
clone Tensor / torch memory_format=preserve_format 真复制；注意 clone 仍会进计算图
cat / stack torch dim=0、out=None cat 沿已有维拼接，stack 新增一维
chunk / split torch chunks/split_size_or_sections、dim=0 切分；chunk 给份数，split 给每份大小
tile / repeat_interleave torch dims / repeats、dim=None 整体平铺 / 逐元素重复
Flatten / Unflatten nn start_dim=1, end_dim=-1 / dim, unflattened_size 写进 Sequential 用，Flatten 默认保留 batch 维
Identity nn — 占位层，方便条件分支里保持结构一致

逐元素数学

名称 子模块 常用关键字参数 说明
add / mul / sub / div torch alpha=1、out=None add(a, b, alpha=2) 等价 a + 2b
add_ / mul_ / zero_ Tensor alpha=1 原地版本，下划线结尾，会改掉原张量
pow / sqrt / exp / log torch out=None 逐元素；log 底是 e，log2 / log10 另算
abs / clamp torch min=None、max=None 截断用 clamp，, 边传 None 表示不设该侧
sigmoid / tanh / relu torch out=None 逐元素激活，等价 Tensor.sigmoid() 等
softmax / log_softmax torch dim、dtype=None 必须显式给 dim，配 NLLLoss 用 log 版
where torch out=None where(cond, a, b)，条件为真取 a
masked_fill Tensor — masked_fill(mask, value)，mask 为 True 处填 value
clamp_min / clamp_max Tensor — 单侧截断的简写，常用于逐元素下限
relu / gelu / silu / dropout nn.functional inplace=False、approximate='none'、p=0.5, training=True 函数式版；F.dropout 的 training 必须自己传

归约 / 统计 / 排序

名称 子模块 常用关键字参数 说明
sum / mean / prod torch dim=None、keepdim=False、dtype=None 不写 dim 就全部归约成一个标量
std / var torch dim=None、correction=1、keepdim=False correction=1 是样本标准差（无偏）
max / min torch dim=None、keepdim=False 带 dim 返回 (values, indices) 二元组；torch.max(a, b) 是两个张量逐元素取大
argmax / argmin torch dim=None、keepdim=False 返回下标；分类预测常用 argmax(dim=1)
amax / amin torch dim=None、keepdim=False 只取值不要下标时用它，避免解包
topk torch k、dim=None、largest=True、sorted=True 返回 (values, indices)，看 top-5 准确率常用
sort torch dim=-1、descending=False、stable=False 返回 (values, indices)
cumsum torch dim、dtype=None 前缀和，算 IoU / 面积常用
unique torch sorted=True、return_counts=False 去重，加 return_counts 顺便拿到频次
norm torch / Tensor p='fro'、dim=None、keepdim=False p 给 2 是 L2，'fro' 是矩阵 Frobenius；新代码建议 torch.linalg.norm
count_nonzero torch dim=None 统计非零个数，配 bool mask 数命中数

线性代数 / 注意力

名称 子模块 常用关键字参数 说明
matmul / @ torch out=None 通用矩阵乘，支持批量广播
mm torch out=None 只接受二维，比 matmul 约束更强
bmm torch out=None 只接受三维批量矩阵乘
einsum torch — 字符串写指标，'bij,bjk->bik' 就是批量矩阵乘
dot / outer torch out=None 一维内积 / 外积
scaled_dot_product_attention nn.functional attn_mask=None、dropout_p=0.0、is_causal=False、scale=None、enable_gqa=False 融合注意力；因果掩码直接给 is_causal=True，GQA 给 enable_gqa=True（K/V 的 head 数少于 Q，且能整除）
MultiheadAttention nn embed_dim, num_heads、dropout=0.0、batch_first=False 多头注意力层，默认维度顺序是 (seq, batch, dim)
normalize nn.functional p=2.0、dim=1、eps=1e-12 按维归一化，余弦相似度前常做

名称 子模块 常用关键字参数 说明

autograd

名称 子模块 常用关键字参数 说明
requires_grad_ Tensor / nn.Module requires_grad=True 就地打开梯度追踪
backward Tensor gradient=None、retain_graph=None、create_graph=False 标量才能直接调；非标量要传 gradient
detach Tensor — 从计算图摘出来，仍共享数据，改它会影响原张量
retain_grad Tensor — 让非叶子张量也留下 .grad，调试时用
register_hook Tensor hook 反向经过该张量时回调，看梯度异常用
grad_fn Tensor — 属性，反向节点；叶子张量是 None
is_leaf Tensor — 属性，叶子张量才默认存 .grad
grad Tensor — 属性，backward 之后梯度存在这里
grad torch.autograd inputs、grad_outputs=None、retain_graph=None、create_graph=False 只求梯度不累积，返回元组
no_grad / inference_mode torch mode=True 评估和推理必须包起来，省显存；inference_mode 更彻底
set_grad_enabled torch mode 函数式开关，按条件临时关梯度

nn.Module 生命周期

名称 子模块 常用关键字参数 说明
Module nn — 自己写模型就继承它，在 __init__ 里注册子层，算逻辑写 forward
forward nn.Module *input 前向逻辑；调用时用 model(x)，不要直接 .forward(x)
train / eval nn.Module mode=True 切换训练/评估，只影响 Dropout、BatchNorm 这类层
parameters / named_parameters nn.Module recurse=True、remove_duplicate=True 交给优化器的就是它，dict 分组时用 named 版
buffers / named_buffers nn.Module recurse=True BatchNorm 的 running_mean 属于 buffer，会进 state_dict 但不是参数
children / modules nn.Module — / remove_duplicate=True 遍历直接子层 / 递归包含自己；只有 modules() 有 remove_duplicate
apply nn.Module fn 递归对每个子模块执行，初始化权重常用
zero_grad nn.Module set_to_none=True 清梯度，默认置 None（不是 0）
register_buffer / register_parameter nn.Module persistent=True 注册 buffer / 参数，别用普通属性挂张量
to nn.Module device、dtype 整体搬迁，返回值要接住，原地改也可以
get_submodule / get_parameter nn.Module target 按点分名字取，写通用工具时用

nn 层

名称 子模块 常用关键字参数 说明
Linear nn in_features, out_features、bias=True 全连接，内部权重形状是 (out, in)
Embedding nn num_embeddings, embedding_dim、padding_idx=None、sparse=False 查表；输入必须是 LongTensor
LayerNorm nn normalized_shape、eps=1e-5、elementwise_affine=True 对最后一维做归一化，Transformer 默认选择
BatchNorm1d / BatchNorm2d nn num_features、eps=1e-5、momentum=0.1、affine=True、track_running_stats=True 依赖 batch 统计，小 batch 别用
Dropout nn p=0.5、inplace=False 训练时随机置零，评估时旁路
Conv1d / Conv2d nn in_channels, out_channels, kernel_size、stride=1、padding=0、dilation=1、groups=1、bias=True padding 可给 'same' 保持尺寸
MaxPool2d / AvgPool2d nn kernel_size、stride=None、padding=0、ceil_mode=False stride=None 时默认取 kernel_size
AdaptiveAvgPool2d nn output_size 直接指定输出尺寸，分类头前常用
Sequential nn *args 顺序容器，可传 OrderedDict 给层命名
ModuleList / ModuleDict nn modules=None 装子层的容器，会被正确注册；普通 list 不会
Parameter nn — 让普通张量进入 parameters()
RNN / LSTM / GRU nn input_size, hidden_size、num_layers=1、batch_first=False、dropout=0.0、bidirectional=False、proj_size=0 默认维度顺序 (seq, batch, feature)，dropout 只在 num_layers > 1 生效
TransformerEncoderLayer nn d_model, nhead、dim_feedforward=2048、dropout=0.1、activation=relu、norm_first=False、batch_first=False 单个编码层，norm_first=True 更接近 GPT 式结构
TransformerEncoder / TransformerDecoder nn encoder_layer/decoder_layer、num_layers、norm=None 把层堆叠起来

损失函数

名称 子模块 常用关键字参数 说明
CrossEntropyLoss nn ignore_index=-100、reduction='mean'、weight=None、label_smoothing=0.0 输入未归一化 logits、目标是类别下标，别自己加 softmax
NLLLoss nn ignore_index=-100、reduction='mean' 配 log_softmax 用
MSELoss nn reduction='mean' 回归默认选择
L1Loss / SmoothL1Loss nn reduction='mean'、beta=1.0 对离群点更稳，检测框回归常用
BCEWithLogitsLoss nn reduction='mean'、pos_weight=None 二分类；输入 logits，自带 sigmoid
cross_entropy / mse_loss / binary_cross_entropy_with_logits nn.functional 同上，reduction='mean' 函数式版，不需要建对象

损失函数共有的 reduction 取 'none' / 'mean' / 'sum'。想要逐样本加权就选 'none'，自己乘权重再求和。

参数初始化

名称 子模块 常用关键字参数 说明
uniform_ / normal_ nn.init a=0.0, b=1.0 / mean=0.0, std=1.0 就地改张量，调用时用 torch.no_grad() 包住更稳
xavier_uniform_ / xavier_normal_ nn.init gain=1.0 适配 tanh / sigmoid，深度网络防梯度消失
kaiming_uniform_ / kaiming_normal_ nn.init a=0、mode='fan_in'、nonlinearity='leaky_relu' ReLU 系列默认选择，a 是负斜率
zeros_ / ones_ / constant_ nn.init val 偏置清零常用
apply nn.Module fn 配合上面写 model.apply(init_fn) 遍历初始化

优化器

名称 子模块 常用关键字参数 说明
SGD torch.optim lr=1e-3、momentum=0、weight_decay=0、nesterov=False lr 有默认值但基本都要自己调，习惯显式写
Adam / AdamW torch.optim lr=1e-3、betas=(0.9,0.999)、eps=1e-8、weight_decay=0 / 0.01 AdamW 的 weight_decay 是解耦实现且默认给到 0.01，优先用它

state_dict / load_state_dict torch.optim.Optimizer — 断点续训要连优化器状态一起存
param_groups torch.optim.Optimizer — 属性，按名字分组的参数，分层学习率靠它

学习率调度

名称 子模块 常用关键字参数 说明
StepLR lr_scheduler step_size、gamma=0.1、last_epoch=-1 每 step_size 个 epoch 乘 gamma
MultiStepLR lr_scheduler milestones、gamma=0.1 在指定 epoch 降，比固定步长灵活
ExponentialLR lr_scheduler gamma、last_epoch=-1 每个 epoch 乘 gamma
CosineAnnealingLR lr_scheduler T_max、eta_min=0.0 余弦退火，T_max 是半个周期长度
OneCycleLR lr_scheduler max_lr、total_steps / epochs+steps_per_epoch、pct_start=0.3、div_factor=25.0 按 step 调用，配合 warmup 效果好
ReduceLROnPlateau lr_scheduler mode='min'、factor=0.1、patience=10、min_lr=0 step(metrics) 传验证指标，指标不降才降 lr
LambdaLR lr_scheduler lr_lambda、last_epoch=-1 自己写函数控制，最灵活
step lr_scheduler epoch=None 多数调度器按 epoch 调；OneCycleLR/ReduceLROnPlateau 例外

保存 / 加载

常见坑

  • view 遇到不连续张量会直接报错，reshape 会自动复制；transpose / permute 之后想 view 先 contiguous()。
  • nn.Flatten 默认 start_dim=1，torch.flatten 默认 start_dim=0，前者保留 batch 维，后者会把 batch 也压掉。
  • CrossEntropyLoss 吃的是 logits，不要再接 softmax；模型输出接 argmax 得到类别就行。
  • Dropout、BatchNorm 在 eval() 下行为不同，评估前一定 model.eval()，推理再包 torch.no_grad()。
  • 优化器的 zero_grad() 默认把梯度置 None，不是置 0；手动读 .grad 前先确认不是 None。
  • 读 GPU 上存的权重，torch.load 要显式给 map_location='cpu'，否则在没有 GPU 的机器上直接失败。
  • DataLoader 用 num_workers > 0 时，Dataset 里的自定义对象要能被 pickle；Windows / macOS 上还要注意 if __name__ == '__main__' 保护。
  • Tensor.numpy() 要求张量不带梯度且不在 GPU 上，跨设备先 .detach().cpu()。
  • torch.compile(model) 后 model.state_dict() 的键会多一层 _orig_mod. 前缀，加载旧 checkpoint 前先看清键名。
