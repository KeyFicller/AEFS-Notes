速览

按主题分组的常用 API。签名与默认值对照本机 Python 3.14.6 核对，= 后面是默认值，没写默认值的表示必填。练习见 qa.ipynb，模块清单一览见 ../stdlib.md。

约定：

  • dumps / loads 面向字符串，dump / load 面向文件对象，多出来的第一个参数就是文件。
  • JSON 只有 6 种类型：object、array、string、number、boolean、null；Python 的类型要多，映射不上的部分靠 default=。

API 速查

序列化（Python → JSON）

名称 常用关键字参数 说明
dumps obj、skipkeys=False、ensure_ascii=True、check_circular=True、allow_nan=True、cls=None、indent=None、separators=None、default=None、sort_keys=False 返回 JSON 字符串
dump obj、fp + 上面全部 写进文件对象，注意 fp 是第二个位置参数
JSONEncoder skipkeys=False、ensure_ascii=True、sort_keys=False、indent=None、separators=None、default=None 编码器类；继承并重写 default 可支持自定义类型

反序列化（JSON → Python）

名称 常用关键字参数 说明
loads s、cls=None、object_hook=None、parse_float=None、parse_int=None、parse_constant=None、object_pairs_hook=None 从字符串解析；s 可以是 str / bytes / bytearray
load fp + 上面全部 从文件对象读并解析
JSONDecoder object_hook=None、parse_float=None、parse_int=None、parse_constant=None、strict=True、object_pairs_hook=None 解码器类
JSONDecodeError — ValueError 子类，带 .msg、.doc、.pos、.lineno、.colno

常用编码选项

名称 常用取值 说明
ensure_ascii False 设 False 才保留中文等非 ASCII 字符，否则转成 \uXXXX
indent 2 / 4 缩进格式化，方便人读；会明显变长
separators (", ", ": ") / (",", ":") 默认紧凑给 (", ", ": ")；indent 非空时默认变成 ("," , ": ")
sort_keys True 按键排序输出，便于 diff 和比对
skipkeys True 遇到非法的 key 类型跳过而不是报错
allow_nan False 默认允许 NaN/Infinity，但这不是标准 JSON；要和别的语言互通就关掉
default 函数 遇到不可序列化对象时调用，返回可序列化的替代值
object_pairs_hook 函数 接收键值对列表，可用来去重、保持顺序或自定义类型

使用用例

1. 字典和文本互转

import json
text = json.dumps(data, ensure_ascii=False)
print(text)
print(json.loads(text)["name"])

2. 写进文件再读出来

import json
with path.open("w", encoding="utf-8") as handle:
    json.dump(data, handle, ensure_ascii=False, indent=4)
with path.open(encoding="utf-8") as handle:
    print(json.load(handle)["age"])

3. 文本不合法

import json
try:
    json.loads(raw)
except json.JSONDecodeError as exc:
    print(type(exc).__name__)

4. 一组对象

import json
loaded = json.loads(json.dumps(data, ensure_ascii=False))
print(loaded[1]["name"])

5. 键按字母序

import json
print(json.dumps(data, sort_keys=True))

6. 日期不能直接写进去

import json
text = json.dumps(data, default=lambda value: value.isoformat())
print(text)

7. 一行一个 JSON

import json
for line in path.read_text(encoding="utf-8").splitlines():
    print(json.loads(line)["name"])

8. 读进来时收成坐标

import json
def as_point(obj):
    return (obj["x"], obj["y"])
print(json.loads(raw, object_hook=as_point))

常见坑

  • JSON 的 key 只能是字符串（数字等会被转换），sort_keys=True 遇到混合类型 key 会报错。
  • 元组会被当数组序列化成 list，反序列化拿不回元组；类型信息要靠约定自己还原。
  • datetime、set、自定义对象都不能直接序列化，要写 default= 或用 JSONEncoder 子类。
  • 写文件时记得 encoding="utf-8" + ensure_ascii=False，否则中文会被转义，读出来还是正常的中文。
  • json.dump 不负责换行和编码；读 Windows 生成的带 BOM 文件用 encoding="utf-8-sig"。
  • 浮点数走的是 repr 精度，超大整数也可能丢精度；要精确表示金额请用字符串或 Decimal。
  • loads 解析失败抛 JSONDecodeError，它同时是 ValueError；给用户的报错信息里带上 .lineno / .colno 更好定位。
  • allow_nan=True 写出的 NaN 不是合法 JSON，别的语言解析会失败；跨语言时设 allow_nan=False。
