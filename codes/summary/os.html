速览

按主题分组的常用 API。签名与默认值对照本机 Python 3.14.6 核对，= 后面是默认值，没写默认值的表示必填。练习见 qa.ipynb，模块清单一览见 ../stdlib.md。

约定：

  • 子模块 一列：os = 顶层函数，os.path = 路径字符串处理，os.environ = 环境变量映射。
  • 路径相关的新代码优先用 pathlib；os 这一套更适合和 C / 系统调用对齐、或需要 dir_fd 的场景。
  • 多数函数返回 str；给 bytes 参数就走字节路径，两种不要混。

使用用例

1. 读一个可能没有的环境变量

print(os.getenv("QA_OS_MISSING", "default"))

2. 给当前进程设一个环境变量

os.environ["QA_OS_COLOR"] = "blue"
print(os.environ["QA_OS_COLOR"])

3. 换一下当前目录，再换回来

previous = os.getcwd()
os.chdir(box)
print(os.getcwd())
os.chdir(previous)

4. 列出这一层的名字

print(sorted(os.listdir(box)))

5. 一次建好多层

target = box / "a" / "b"
os.makedirs(target, exist_ok=True)
os.makedirs(target, exist_ok=True)
print(os.path.exists(target))

6. 把子目录里的文件都找出来

paths = []
for dirpath, _, filenames in os.walk(box):
    for name in filenames:
        paths.append(os.path.join(dirpath, name))
print(sorted(paths))

常见坑

  • os.makedirs("a/b", exist_ok=True) 才是可重复执行的写法；漏了 exist_ok 第二次跑就 FileExistsError。
  • listdir 返回的是名字不是路径，拼回路径要 os.path.join；顺序不保证，需要顺序就自己 sorted。
  • os.path.join("a", "/b") 得到 /b，绝对路径会重置前缀，和 pathlib 的 / 是同一套规则。
  • os.remove 和 os.unlink 是同一个函数；删目录要 rmdir，非空目录用 shutil.rmtree。
  • os.system 拿不到输出、还受 shell 注入影响；需要输出和退出码请用 subprocess.run。
  • 改过的环境变量只对当前进程和之后创建的子进程生效，父 shell 不受影响。
  • walk(topdown=True) 时可以原地改 dirnames 来剪枝；followlinks=True 要防符号链接成环。
