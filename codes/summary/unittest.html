A

速览

按主题分组的常用 API。签名与默认值对照本机 Python 3.14.6 核对，= 后面是默认值，没写默认值的表示必填。练习见 qa.ipynb，模块清单一览见 ../stdlib.md。

约定：

  • 测试类继承 TestCase，方法名以 test_ 开头才会被发现。
  • 断言用 self.assertXxx，别用裸 assert：前者报错信息更全，也能被 runner 统计。
  • 运行入口是 python -m unittest，支持 discover、-k 过滤、-v 详情。

用例与生命周期

名称 常用关键字参数 说明
TestCase methodName='runTest' 测试基类；类方法名以 test_ 开头

使用用例

1. 断言相等

import unittest
class TestAdd(unittest.TestCase):
    def test_add(self):
        self.assertEqual(add(2, 3), 5)
unittest.TextTestRunner().run(
    unittest.defaultTestLoader.loadTestsFromTestCase(TestAdd)
)

2. 断言包含

import unittest
class TestItems(unittest.TestCase):
    def test_items(self):
        self.assertIn("b", items)
unittest.TextTestRunner().run(
    unittest.defaultTestLoader.loadTestsFromTestCase(TestItems)
)

3. 断言抛出异常

import unittest
class TestParse(unittest.TestCase):
    def test_parse(self):
        with self.assertRaises(ValueError):
            parse("x")
unittest.TextTestRunner().run(
    unittest.defaultTestLoader.loadTestsFromTestCase(TestParse)
)

4. setUp

import unittest
class TestData(unittest.TestCase):
    def setUp(self):
        self.data = [1, 2, 3]
    def test_length(self):
        self.assertEqual(len(self.data), 3)
    def test_sum(self):
        self.assertEqual(sum(self.data), 6)
unittest.TextTestRunner().run(
    unittest.defaultTestLoader.loadTestsFromTestCase(TestData)
)

5. 浮点近似相等

import unittest
class TestFloat(unittest.TestCase):
    def test_float(self):
        self.assertAlmostEqual(0.1 + 0.2, 0.3)
unittest.TextTestRunner().run(
    unittest.defaultTestLoader.loadTestsFromTestCase(TestFloat)
)

6. 多组输入

import unittest
class TestAdd(unittest.TestCase):
    def test_add(self):
        for a, b, expected in cases:
            with self.subTest(a=a, b=b):
                self.assertEqual(add(a, b), expected)
unittest.TextTestRunner().run(
    unittest.defaultTestLoader.loadTestsFromTestCase(TestAdd)
)
D

常见坑

  • 类名或方法名不以 test 开头就不会被发现；discover 只认目录里 test*.py 模式。
  • setUpClass / tearDownClass 漏了 @classmethod 会报错；类级状态别在实例级 setUp 里改。
  • assertRaises 写成 self.assertRaises(ValueError, func, arg) 能断言，但拿不到异常对象；要看消息用 with self.assertRaises(ValueError) as cm:。
  • 用裸 assert 在 python -O 下会被优化掉，测试会静默通过。
  • patch 的目标是「使用处」而不是「定义处」：要 patch mymodule.time.time，不是 time.time。
  • patch 装饰器顺序和参数顺序相反，写多个容易错，能用 with 就用 with。
  • 测试之间要独立，别依赖执行顺序或共享可变状态；需要重置的东西放 setUp / addCleanup。
  • 异步测试要用 IsolatedAsyncioTestCase，普通 TestCase 里的 async def test_ 根本不会被 await。
  • verbosity、failfast 等也可以走命令行：python -m unittest -v -f -k pattern。
