A

速览

按主题分组的常用 API。签名与默认值对照本机 Python 3.14.6 核对，= 后面是默认值，没写默认值的表示必填。练习见 qa.ipynb，模块清单一览见 ../stdlib.md。

约定：

  • math 面向标量 float，精度有限；要任意精度用 decimal，要数组运算用 numpy。
  • 大多数函数遇到定义域外输入抛 ValueError（如 math.sqrt(-1)），溢出抛 OverflowError。
  • int 输入会被转成 float；只有 isqrt、factorial、comb、gcd 等明确返回整数。

使用用例

1. 平方根与圆周率

import math
print(math.pi * r ** 2)

2. 向上 / 向下取整

import math
print(math.floor(x))
print(math.ceil(x))

3. 最大公约数

import math
print(math.gcd(a, b))

4. 浮点是否接近

import math
print(math.isclose(u, v))

5. 角度与弧度

import math
print(math.sin(math.radians(90)))

6. 把结果写入文件

import math
path.write_text(f"{math.sqrt(16)}\n{math.factorial(5)}\n", encoding="utf-8")
print(path.read_text(encoding="utf-8"))
D

常见坑

  • 别用 x == y 比较浮点，用 math.isclose(a, b, rel_tol=...)。
  • math.sqrt(-1) 抛 ValueError 而不是返回复数；要复数用 cmath。
  • isqrt 返回整数，sqrt 返回浮点；大整数求平方根用 isqrt 不会丢精度。
  • math.log(x, base) 对有些底（如 2、10）不如专门的 log2、log10 精确。
  • round() 是内置函数，采用银行家舍入；math 里没有 round。
  • math.inf - math.inf、math.inf / math.inf 都是 nan，判断前先 isnan。
  • sum() 加很多浮点会累积误差，金融或科学计算用 fsum。
  • 常量和函数都在 math 命名空间里，别 from math import *，e、pi 太容易和变量名冲突。
