A

速览

按主题分组的常用 API。签名与默认值对照本机 Python 3.14.6 核对，= 后面是默认值，没写默认值的表示必填。练习见 qa.ipynb，模块清单一览见 ../stdlib.md。

约定：

  • @dataclass 根据类里带注解的字段自动生成 __init__、__repr__、__eq__ 等。
  • 字段的默认值写在类属性上；不可变的默认值直接写，可变的默认值必须用 field(default_factory=…)。
  • 字段顺序要求「无默认值」在前；用 kw_only=True 或 field(kw_only=True) 可以绕开。

使用用例

1. 声明并构造

from dataclasses import dataclass
@dataclass
class Point:
    x: int
    y: int
print(Point(3, 4))

2. 默认值

from dataclasses import dataclass
@dataclass
class User:
    name: str
    score: int = 0
print(User("Ada").score)

3. 可变默认要用 factory

from dataclasses import dataclass, field
@dataclass
class Bag:
    tags: list[str] = field(default_factory=list)
a, b = Bag(), Bag()
a.tags.append("x")
print(a.tags)
print(b.tags)

4. 转成字典

from dataclasses import asdict
print(asdict(book))

5. 替换字段得到新实例

from dataclasses import replace
print(replace(p, x=9))
print(p)

6. 冻结后写入文件

from dataclasses import dataclass, asdict
import json
@dataclass(frozen=True)
class Config:
    host: str
    port: int
cfg = Config("localhost", 8080)
path.write_text(json.dumps(asdict(cfg)), encoding="utf-8")
print(path.read_text(encoding="utf-8"))

常见坑

  • 可变默认值（list、dict、set）不能直接写 x: list = []，会共享同一个对象；必须 field(default_factory=list)。
  • 字段有默认值的不能排在无默认值字段前面，否则类定义时就报错；要么调顺序，要么 kw_only=True。
  • frozen=True 只挡字段赋值，__post_init__ 里要用 object.__setattr__ 才能设值。
  • slots=True 会重新生成一个新类并丢掉原来的 __dict__，依赖动态属性的写法会失效。
  • asdict 会深拷贝并递归展开，遇到循环引用会无限递归；大对象只想要顶层字段就自己写 dict 推导。
  • eq=True 但 frozen=False 时生成的 __hash__ 是 None，实例不可哈希；要进 set / dict 键得分清楚 eq 和 frozen。
  • default_factory 传的是函数本身（list），不是调用结果（list()），写成后者会把同一个对象给所有实例。
  • order=True 是按字段顺序逐个比较，字段里混了不可比较类型会在运行时才炸。
