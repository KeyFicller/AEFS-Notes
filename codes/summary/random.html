速览

按主题分组的常用 API。签名与默认值对照本机 Python 3.14.6 核对，= 后面是默认值，没写默认值的表示必填。练习见 qa.ipynb，模块清单一览见 ../stdlib.md。

约定：

  • 顶层函数共享一个全局 Random 实例，seed() 影响的是它。
  • 伪随机数，不能用于安全场景（令牌、密码、验证码）；安全用途用 secrets 或 random.SystemRandom。
  • 同一 seed 在同一版本内结果可复现，跨 Python 大版本不保证完全一致。

API 速查

基本随机

名称 常用关键字参数 说明
random — [0.0, 1.0) 的浮点数
randint a、b 闭区间 [a, b] 的整数，两端都能取到
randrange start、stop=None、step=1 语义同内置 range，randrange(5) 是 [0, 5)
getrandbits k 返回 k 位随机整数
randbytes n 返回 n 字节随机数据（3.9+）
uniform a、b [a, b] 浮点，端点是否可取取决于舍入

序列操作

名称 常用关键字参数 说明
choice seq 等概率取一个元素，序列不能为空
choices population、weights=None、cum_weights=None、k=1 有放回抽 k 个，可加权；weights 和 cum_weights 二选一
sample population、k、counts=None 无放回抽 k 个不重复元素；counts 支持重复元素
shuffle x 原地打乱 list，返回 None

分布

名称 常用关键字参数 说明
gauss / normalvariate mu=0.0、sigma=1.0 正态分布；gauss 更快，normalvariate 更标准
lognormvariate mu、sigma 对数正态分布
expovariate lambd=1.0 指数分布；lambd 是速率，不是均值
triangular low=0.0、high=1.0、mode=None 三角分布，mode 默认取中点
betavariate / gammavariate alpha、beta Beta / Gamma 分布

种子与实例

名称 常用关键字参数 说明
seed a=None、version=2 固定全局随机种子；a=None 用系统熵
getstate / setstate state 存取随机数生成器内部状态，可精确复现某一段
Random x=None 独立的生成器实例，互不干扰，推荐在库里用
SystemRandom — 用 os.urandom，密码学安全，但没有 seed 语义

使用用例

1. 固定种子后取整数

import random
random.seed(42)
print(random.randint(1, 6))

2. 从序列里抽一个

import random
random.seed(0)
print(random.choice(colors))

3. 抽样多个（不放回）

import random
random.seed(1)
print(random.sample(nums, 3))

4. 原地打乱

import random
random.seed(7)
random.shuffle(deck)
print(deck)

5. 浮点区间

import random
random.seed(3)
print(random.random())

6. 加权抽取

import random
random.seed(5)
print(random.choices(["A", "B", "C"], weights=[1, 1, 8], k=1)[0])
D

常见坑

  • random 不是安全随机源；生成密码、token、验证码请用 secrets.token_hex / secrets.choice。
  • randint(0, 1) 返回 0 或 1 各 50%，如果要布尔值不如 random() < 0.5 直白。
  • randrange / randint 的区间开闭不同：randint 两端都含，randrange 不含 stop。
  • choice 只能给序列，给集合要先 list(...)；空序列会 IndexError。
  • choices 有放回、sample 无放回且要求 k <= len(population)，别把两者当成一个。
  • shuffle 原地改并返回 None，别写 x = random.shuffle(seq)。
  • 库里别用模块级函数，会污染全局随机流；建 rng = random.Random(seed) 用自己的实例。
  • 只调 random.seed 不一定能让程序完全可复现，其他库（numpy、hash 随机化）有自己的随机源。
