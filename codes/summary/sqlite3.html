速览

按主题分组的常用 API。签名与默认值对照本机 Python 3.14.6 核对，= 后面是默认值，没写默认值的表示必填。练习见 qa.ipynb，模块清单一览见 ../stdlib.md。

约定：

  • 子模块 一列：sqlite3 = 模块级函数/常量，Connection = 连接对象，Cursor = 游标对象。
  • SQL 里的参数占位一律用 ?（qmark）或 :name（named），值从第二个参数传，不要用字符串拼接。
  • SQLite 是动态类型，列声明只是「亲和性」提示；存储类型在写入时按值决定。

使用用例

1. 建表并插入一行

import sqlite3

with sqlite3.connect(db) as conn:
    # CREATE TABLE：建表。TEXT / INTEGER 是列类型。
    conn.execute("CREATE TABLE people(name TEXT, score INTEGER)")
    # INSERT：插入一行。? 是占位符，值放在后面的元组里。
    conn.execute("INSERT INTO people(name, score) VALUES (?, ?)", ("Ada", 90))
    # SELECT：查询。fetchone() 取一行，结果是 (name, score)。
    row = conn.execute("SELECT name FROM people").fetchone()
    print(row[0])

2. 用占位符查询

with sqlite3.connect(db) as conn:
    # WHERE score >= ? ：筛选。? 换成 80，不要写成 f"...{80}"。
    rows = conn.execute(
        "SELECT name FROM people WHERE score >= ?",
        (80,),
    ).fetchall()
    for row in rows:
        print(row[0])

3. 一次插入多行

with sqlite3.connect(db) as conn:
    # executemany：同一条 INSERT 喂多行。
    conn.executemany("INSERT INTO people(name, score) VALUES (?, ?)", rows)
    # COUNT(*)：行数。
    print(conn.execute("SELECT COUNT(*) FROM people").fetchone()[0])

4. 提交后重开还能读到

import sqlite3

conn = sqlite3.connect(db)
conn.execute("CREATE TABLE people(name TEXT)")
conn.execute("INSERT INTO people(name) VALUES (?)", ("Ada",))
conn.commit()  # 不 commit，关掉后数据不会留下
conn.close()

conn = sqlite3.connect(db)
print(conn.execute("SELECT name FROM people").fetchone()[0])
conn.close()

5. 按列名取值

with sqlite3.connect(db) as conn:
    # Row 让结果能用列名取值：row["name"]，而不只是 row[0]。
    conn.row_factory = sqlite3.Row
    row = conn.execute("SELECT name, score FROM people").fetchone()
    print(row["name"])

6. 更新一行

with sqlite3.connect(db) as conn:
    # UPDATE ... SET ... WHERE：改符合条件的行。
    conn.execute("UPDATE people SET score = ? WHERE name = ?", (100, "Ada"))
    print(conn.execute("SELECT score FROM people WHERE name = ?", ("Ada",)).fetchone()[0])
D

常见坑

  • 写操作必须 commit()，或把语句放进 with conn: 块；后者提交/回滚但不会关闭连接。
  • check_same_thread=True（默认）时连接不能跨线程用；要在多线程里共享得自己加锁并显式关掉该检查。
  • execute("... %s" % x) 是 SQL 注入；永远用 execute("... ?", (x,))。
  • 游标 fetchall() 之后再 fetchone() 返回 None；结果要复用先转 list 或重新查询。
  • rowcount 对 SELECT 不可靠（可能返回 -1），别拿它当结果条数。
  • create_function 注册的函数异常会被包成 OperationalError，出错信息里不一定有 Python 栈。
  • :memory: 每个连接一个独立数据库，connect(":memory:") 两次拿到的是两个空库。
  • 默认把 datetime 存成字符串；要类型往返就设 detect_types=PARSE_DECLTYPES 并自己注册适配器。
  • sqlite3.version / version_info 在 3.14 已移除，只能用 sqlite3.sqlite_version。
  • isolation_level 与 3.12 新增的 autocommit 是两套模型，别混用；新代码建议显式设 autocommit。
