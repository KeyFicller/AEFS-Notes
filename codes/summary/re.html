A

速览

按主题分组的常用 API。签名与默认值对照本机 Python 3.14.6 核对，= 后面是默认值，没写默认值的表示必填。练习见 qa.ipynb，模块清单一览见 ../stdlib.md。

约定：

  • 子模块 一列：re = 顶层函数，Pattern = re.compile 出来的模式对象方法，Match = 匹配结果对象方法。
  • 正则字符串一律用原始字符串 r"..."，避免 \d、\b 被 Python 先转义。
  • 顶层函数每次都要编译并走缓存；要重复使用就显式 re.compile 存起来。

API 速查

匹配入口

名称 子模块 常用关键字参数 说明
compile re pattern、flags=0 返回 Pattern，内部有缓存但显式编译更直观
match re pattern、string、flags=0 只从开头匹配，不要求匹配到结尾
fullmatch re pattern、string、flags=0 整串必须完全匹配
search re pattern、string、flags=0 任意位置找第一个，最常用
escape re pattern 转义元字符，用来把普通字符串当字面量拼进模式
purge re — 清空编译缓存，一般用不到

查找与替换

名称 子模块 常用关键字参数 说明
findall re / Pattern pattern、string / string、pos=0、endpos=… 返回所有匹配；有分组时返回分组内容，多分组返回元组
finditer re / Pattern 同上 返回 Match 迭代器，能拿到位置信息，比 findall 信息全
sub re / Pattern pattern、repl、string、count=0、flags=0 替换，返回新串；count=0 表示全部
subn re / Pattern 同上 返回 (新串, 替换次数)
split re / Pattern pattern、string、maxsplit=0、flags=0 按模式切分，有捕获组时组内容也会保留

标志

名称 子模块 说明
IGNORECASE re 忽略大小写
MULTILINE re ^ / $ 匹配每一行的首尾
DOTALL re 让 . 也匹配换行
VERBOSE re 忽略空白并支持 # 注释，写长正则时用
ASCII re 让 \w、\d 只匹配 ASCII，不匹配 Unicode
NOFLAG re 0，表示不带标志

使用用例

1. 找第一个匹配

import re
m = re.search(r"\d+", text)
print(m.group() if m else None)

2. 找出全部

import re
print(re.findall(r"[A-Za-z]+", text))

3. 取出分组

import re
m = re.search(r"(.+):(\d+)", text)
print(m.group(1))
print(m.group(2))

4. 替换

import re
print(re.sub(r"\d+", "#", text))

5. 忽略大小写

import re
print(bool(re.search(r"\berror\b", text, flags=re.IGNORECASE)))

6. 从文件里抽邮箱

import re
text = path.read_text(encoding="utf-8")
found = re.findall(r"[\w.-]+@[\w.-]+\.[\w.-]+", text)
print(list(dict.fromkeys(found)))

常见坑

  • re.match 只在开头匹配，等价于模式前加了 ^；想任意位置找用 search。
  • 顶层函数每次调用都查缓存，re.compile 后复用更快，尤其在循环里。
  • . 默认不匹配换行，多行文本忘了 DOTALL 会漏匹配。
  • 分组只想要括号不想要捕获，用非捕获组 (?:...)；findall 有分组时结果形态会变，容易踩。
  • *、+、? 是贪婪的，加 ? 变非贪婪（.*?）；但回头改结构往往比调贪婪更稳。
  • 替换串里的 \1 是反斜杠转义，普通字符串里要写成 r"\1"；命名组用 \g<name> 更清楚。
  • 嵌套量词（如 (a+)+$）会引发灾难性回溯，长文本上要避免；能用锚点或原子组就收窄。
  • $ 默认匹配整串末尾或结尾换行前；要严格行尾配 MULTILINE 或 \Z。
