速览

按主题分组的常用 API。签名与默认值对照本机 Python 3.14.6 核对，= 后面是默认值，没写默认值的表示必填。练习见 qa.ipynb，模块清单一览见 ../stdlib.md。

约定：

  • Path 是带 I/O 的具体实现；PurePath / PurePosixPath / PureWindowsPath 只做字符串层面的路径运算，不碰磁盘。
  • 属性（name、suffix、parent …）不带括号；方法带括号。
  • 大写 ROOT 之类只是命名习惯，pathlib 本身不区分大小写。

API 速查

构造与平台入口

名称 常用关键字参数 说明
Path *pathsegments Path("a", "b") 与 Path("a/b") 等价；不检查路径是否存在
PurePath / PurePosixPath / PureWindowsPath *pathsegments 纯计算版；跨平台判断 Windows 路径时用
cwd — 类方法，返回当前工作目录
home — 类方法，返回 ~ 展开后的目录

拼接 / 拆解

名称 常用关键字参数 说明
/ — 运算符重载，推荐写法：root / "src" / "app.py"
joinpath *pathsegments / 背后的方法，一次拼多段
name / stem / suffix / suffixes — 文件名 / 去后缀主名 / 末段后缀（含点）/ 全部后缀列表
parent / parents — 上级目录 / 所有祖先，parents[0] 就是 parent
parts / anchor / drive / root — 拆成各段 / 盘符加根 / 盘符 / 根
with_name name 只换最后一段文件名
with_stem stem 只换主名，保留后缀
with_suffix suffix 换后缀，'' 可去掉后缀；不改文件
relative_to other、walk_up=False 算相对路径，walk_up=True 允许用 .. 回退（3.12+）
is_relative_to other 判断是否在另一路径之下，比字符串前缀可靠
as_posix / as_uri — 正斜杠字符串 / file: URI
__fspath__ — 实现 os.PathLike，可直接丢给 open()、os 函数

判断 / 解析

名称 常用关键字参数 说明
exists / is_dir / is_file / is_symlink follow_symlinks=True 存在性判断；is_symlink 没有该参数
resolve strict=False 转绝对路径并解析符号链接；strict=True 时不存在就报错
absolute — 只补绝对路径，不解析 .. 和链接
expanduser — 展开 ~ 和 ~user
stat / lstat follow_symlinks=True 类似 os.stat，返回 os.stat_result
samefile other_path 是否指向同一个实际文件
owner / group follow_symlinks=True 属主 / 属组名字
match path_pattern、case_sensitive=None 用 glob 风格匹配，从末段往前比对

读写文件

名称 常用关键字参数 说明
open mode='r'、buffering=-1、encoding=None、errors=None、newline=None 返回文件对象，参数与内置 open 一致
read_text / read_bytes encoding=None、errors=None、newline=None 一次读完并关闭
write_text / write_bytes data、encoding=None、errors=None、newline=None 一次覆盖写；不会追加，也不自动建父目录
touch mode=0o666、exist_ok=True 建空文件或更新 mtime；exist_ok=True 时重复调用不报错

目录操作

名称 常用关键字参数 说明
mkdir mode=0o777、parents=False、exist_ok=False parents=True 连父目录一起建；重复建要配 exist_ok=True
rmdir — 只能删空目录；非空用 shutil.rmtree
iterdir — 只看当前这一层，返回迭代器，顺序不保证
glob / rglob pattern、case_sensitive=None、recurse_symlinks=False glob 只看一层，rglob 递归；只返回已存在项
walk top_down=True、on_error=None、follow_symlinks=False 生成 (dirpath, dirnames, filenames)，3.12+

改名 / 删除 / 链接

名称 常用关键字参数 说明
rename / replace target 改名；目标存在时 replace 覆盖，rename 在 Windows 上会失败
unlink missing_ok=False 删文件或链接；missing_ok=True 时不存在也不报错
symlink_to target、target_is_directory=False 建符号链接；Windows 上要权限
hardlink_to target 建硬链接
readlink — 读符号链接指向的目标

使用用例

1. 拼接，再拆开

path = root / "src" / "app.py"
print(path.name, path.stem, path.suffix, path.parent)

2. 写入再读出

notes = box / "notes.txt"
notes.write_text(text)
print(notes.read_text())

3. 一次建好多层

target = box / "a" / "b"
target.mkdir(parents=True, exist_ok=True)
target.mkdir(parents=True, exist_ok=True)
print(target.is_dir())

4. 只看当前这一层

files, dirs = [], []
for item in box.iterdir():
    (dirs if item.is_dir() else files).append(item.name)
print(sorted(dirs))
print(sorted(files))

5. 含子目录的全部 .py

for path in sorted(p.relative_to(box) for p in box.rglob("*.py")):
    print(path)

6. 换后缀，再改名

dest = src.with_suffix(".md")
print(dest)
src.rename(dest)
print(src.exists())

7. 相对路径不许跳出沙箱

for rel in (inside, outside):
    full = (sandbox / rel).resolve()
    print(full, full.is_relative_to(sandbox))
D

常见坑

  • Path("/a") / "/b" 结果是 /b：右侧是绝对路径时会丢掉左边，拼接前先确认没有前导 /。
  • resolve() 默认 strict=False，路径不存在也能返回；要看真实性别拿它当 exists()。
  • iterdir() 和 glob() 返回的是迭代器，遍历一次就耗尽；要反复用先 list(...) 或 sorted(...)。
  • write_text() 是整文件覆盖，追加得用 open("a")；父目录不存在会直接报错，先 mkdir(parents=True, exist_ok=True)。
  • relative_to() 只接收真正的下级路径；能含 .. 的是 is_relative_to() 和 walk_up=True，别混用。
  • suffix 只认最后一段，.tar.gz 的 suffix 是 .gz，要 .suffixes 才拿到 ['.tar', '.gz']。
  • Path 对象可以直接当 str 用（os.fspath），但比较路径别比字符串，用 samefile() 或 resolve() 后比。
  • 3.12 起才有 Path.walk、relative_to(walk_up=)；3.13 起 glob 才支持 recurse_symlinks。
