# 示例

以英雄点是否落地评判；勿照抄分区。出图只走 SKILL「出图流水线」（`cursor` → `GenerateImage`）。每次生成后 Read attempt PNG + [evaluator.md](evaluator.md)（≥85；初稿 + 至多 1 次重画）。

语气样例（非必填）：

```
英雄点: 点积几何直觉
标题: 向量是有方向的积木
Motto: 方向对了，长度只是音量
目标: 会用点积判断朝没朝一块
主视觉: 两箭头 + 影子投影
支撑: 费曼一句；np.dot vs 手写
```

疏朗卡通海报；非英雄槽位可丢。

模型课语气样例（留白则画在章节卡；丰满则同样描述用于 `archi-` 旁卡）：

```
英雄点: ResNet 残差捷径
标题: 残差是加回去的近路
主视觉: stem → 残差块堆叠；块内 F(x)+x 捷径箭头
支撑: 捷径解决深层退化（仅当章节卡留白够）
```
