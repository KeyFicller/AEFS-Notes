# 学习方法

Motto → Problem → Concept → Build → Use → Ship，再把高价值点落成 PNG 英雄点。

**项目指向 AI 工程。** 分流三维：**AI 关联度 × 本课主题关联度 × 工程落地重要性**；双高/三高上卡，纯数学冷门或与训练/推理/LLM/生成弱相关 → 缩小或丢。同一机制优先用课文里的 AI 用法锚定（Connection to ML / Use It）。

## 可选栈

1. 目标（学完能做啥 · 最好能接到 AI 管线）
2. 提取线索（常即英雄点图；先找 AI 锚点）
3. Build→Use（仅当生产跃迁是重点）
4. 费曼一句（能澄清英雄点才写）
5. FR：核对用，不上卡、不改英雄点

## 课型

- 数学：验算/恒等式可当英雄点，但须能接到模型/训练/推理/评测之一
- 工程：失败模式/生产惯用法可当英雄点
- 与学习者栈（Python / PyTorch / LangChain / LangGraph）双高重合的生产 punchline → **应上卡**（短可读，非整文件）

## 裁剪测试

手机可读？三秒认出英雄点？是这周会用的点？**和 AI 工程有没有直接钩子？** 否 → 放大要点、砍装饰、重画。
