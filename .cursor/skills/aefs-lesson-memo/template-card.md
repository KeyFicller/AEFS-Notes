# PNG 版式

英雄点按 SKILL 选；**一张** PNG；版式跟强调走，无固定分区。

## 画布

- 比例：`3:4` 默认；需纵向用 `9:16`
- 风格：手绘/软卡通/公众号卡；纸感或浅网格；墨线；粉彩
- 语言：中文为主（术语可英）
- 避免：干白底、紫光仪表盘

## 图层（可重排）

| 层 | 内容 | 注意 |
|----|------|------|
| 身份 | 眉头/标题/Motto/目标 | 轻，别抢英雄 |
| 英雄 | 1–2 必记点 | 最大：图解/代码/公式… |
| 支撑 | 便签、数字钩、Build/Use | 仅澄清英雄时用 |
| 边角 | 坑 | 小；不要自测 |

例：机制课管线居中、**双高生产代码贴英雄旁**（如 device 选择）；公式课大号等式；工程课失败三格可当英雄。缺席优于硬塞。

## 密度

手机可读；短标签；生产代码够 punchline 即可（1–3 行）。无 URL、无答案。

## 路径

`notes/cards/<phaseDir>/<lessonDir>.png`（与 SKILL 路径派生一致；禁止 `notes/cards/*--*.png`）
